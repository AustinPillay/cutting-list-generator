# Cutting List Generator

An Excel tool that transformed a complex, expert-only process into a simple step-by-step input form. What previously took an experienced cabinetmaker multiple days now takes minutes.

---

## The Problem

Generating a cutting list for a custom cabinetry job requires deep knowledge of joinery, material yield, part labelling, and sheet optimisation. It's the kind of work that can only be done by someone who really knows what they're doing — and it takes a long time.

---

## What It Does

- Guides the user through job inputs step by step
- - Calculates all part dimensions automatically from the inputs
  - - Outputs a complete, labelled cutting list ready for the workshop
    - - Eliminates the need for expert knowledge to produce an accurate list
     
      - ---

      ## Tech Stack

      `Microsoft Excel` — Data validation, structured input forms, formula-driven output

      ---

      ## The Result

      A task that required expert knowledge and multiple days was reduced to a guided form that anyone on the team could complete. This is the kind of tool I care most about building — one that gives capability to people who didn't have it before.
